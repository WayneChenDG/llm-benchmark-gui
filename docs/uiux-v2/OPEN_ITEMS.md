## 未接入但已在 UI 中做成可用动作的能力
- **打包证据（ZIP）**：基于既有 `results/runs/<run_id>/` 产物打包，功能可用；ZIP 内含演示数据标注。
- **打开所在目录**：调用系统文件管理器，功能可用。
- **载入演示配置**（总览页）：一键把参数指向本地 mock 端点，仅用于演示与回归，不影响真实测试参数（可覆盖）。

## 明确未做（超出「只改 UI/UX」边界）
- 未改 runner / metrics / stream_parser / result_store / result_db 的任何计算与产物格式。
- 未新增测试类型、未改并发模型、未引入 tokenizer（TPOT/ITL 口径保持既有：ITL 为 SSE chunk 级近似）。
