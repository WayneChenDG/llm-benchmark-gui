# 已修改页面清单（UI/UX v2）

页签由 5 个调整为 7 个，信息层级按「总览 → 建测 → 结果 → 扫测 → 对比 → 交付 → 环境」组织。

| # | 页签（zh / en） | 状态 | 主要改动 |
|---|---|---|---|
| 0 | 总览 / Overview | **新增页面** | 最近一轮关键指标（TTFT 平均 / TPOT 平均 / Output 吞吐 / 成功率，带口径小字）＋ 数据来源行；当前配置与环境速览＋动作按钮（新建测试 / 载入演示配置 / 查看最近报告）；待处理事项（失败请求、演示数据提示）；最近运行表（时间 / 模型 / 负载 / TTFT / Output TPS / 成功率 / 数据来源） |
| 1 | 新建测试 / New Test | 重构外观 | 参数分组、单位标注、预设（快速校准 / 标准基线）可读化；窗口可缩放后布局不再挤压 |
| 2 | 测试与结果 / Test & Results | 重构外观 | 服务连接 / 基础测试 / 压力测试 / 测试耗时状态卡；结果摘要 8 项指标卡（单位 + 口径 tooltip）；E2E 延迟分布图（品牌色、去重复标题）；详细报告；演示数据提示横幅 |
| 3 | 并发扫测 / Concurrency Sweep | 重构外观 | 沿用既有扫测逻辑，统一卡片/表格/状态样式 |
| 4 | 历史对比 / History & Compare | 混合 | 历史列表（13 列，固定列宽 + 横向滚动，表头带单位）；历史详情预览；**开始对比**（运行 A/B 选择项带「[演示]」标注）＋「不可直接比较」差异提示表（并发/请求数/负载差异逐项列出）＋指标对比表（单位 / 差值 / 变化） |
| 5 | 报告与证据 / Reports & Evidence | **新增页面** | 选择运行（下拉，演示运行带标注）；打开所在目录 / 打包证据（ZIP）；运行证据块（运行 ID / 时间 / 类型 / 模型 / 端点 / 环境档案 / 硬件 / 推理框架 / 模型档案 / 负载 / 并发 / 请求数 / 数据来源）；交付件清单（文件 / 类型 / 大小，来自 artifacts_manifest.json） |
| 6 | 环境档案 / Environment | 重构外观 | 统一卡片与表格样式（沿用既有逻辑） |

页面内一致性改动（跨页统一口径）：
- 指标卡：性能类统一品牌蓝左色条，语义色仅用于表达健康/异常（成功率）；延迟/吞吐指标不再用红/琥珀。
- 表格：表头一律带单位（`TTFT (ms)`、`Output TPS (tok/s)`、`成功率 (%)`、`TTFT P95 (ms)`、`E2E P95 (ms)`）；列宽不小于表头文字宽，超宽表格用横向滚动而非压缩。
- 空态：统一「标题 + 说明 + 下一步」样式；无运行时不显示空卡片（证据块给出引导文案、导出按钮置为禁用态）。
- 演示数据标注：总览横幅、测试与结果提示横幅、历史对比选择项标签、报告与证据证据块/导出件，共四处。
- 主题：窗口可缩放（可放大到 1600×1000，最小 1248×792）；ttk 主题与控件焦点/悬停/禁用态统一。
